# AlternaTech Job Board

Full-stack Job Board project developed by Kanan and Charles.

## Technologies

- HTML
- CSS
- JavaScript
- PHP
- PDO
- MySQL / MariaDB
- REST API

## Project concept

AlternaTech is a Job Board focused on IT, Data, AI, Cybersecurity, Cloud and Development opportunities in France.

The platform will support:
- Job listings
- Job details without page reload
- Applications
- User registration and login
- Admin dashboard
- CRUD operations
- France Travail API integration
